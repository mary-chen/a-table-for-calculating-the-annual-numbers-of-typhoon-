# a-table-for-calculating-the-annual-numbers-of-typhoon-
A table for calculating the annual numbers of typhoon 
Update after each Feb next year.
After updating, U can use the data to calculate the annual numbers of typhoon in next year.
The last 15 years date will change, but have little influence on the effect of the calculating.
The first releases contents more informations, but only the fisrt sheet is included in the new releases.
